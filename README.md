# Металлобаза — веб-проект

Страница проекта «Металлобаза» и навигация к его WordPress-теме.

## Реализация

[**metallobaza3-theme — исходный код темы**](https://github.com/DenisChernykh/metallobaza3-theme)

В теме находятся PHP-шаблоны шапки, подвала и страницы, подключение ресурсов через WordPress и frontend-сборка на Vite/Sass.

## Что смотреть работодателю

Разработку собственной CMS-темы, интеграцию серверных шаблонов с CSS/JavaScript и организацию frontend-ресурсов в PHP-проекте. Код и команды сборки доступны в [README темы](https://github.com/DenisChernykh/metallobaza3-theme#readme).
