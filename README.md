# Металлобаза — интернет-магазин на WordPress

Собственная WordPress-тема для продажи металлопроката и строительных материалов. Каталог, фильтры, товарные варианты, избранное, корзина и оформление заказа связаны с CMS и плагином VICTORY Group Catalog, исходники которого включены в репозиторий.

## Возможности

- Страницы каталога, категории, карточки товара, поиск, сортировка и пагинация.
- Выбор вариантов товара, количество, скидки и расчёт итогов корзины.
- Корзина и оформление заказа; состояние интерфейса через WordPress Interactivity API.
- Управление контентом и настройками через Carbon Fields.
- Страницы доставки, гарантий, контактов, новостей и специальных предложений.
- Обработка форм через VG_Mailer с настраиваемыми каналами доставки.

## Что показывает проект

Разработку коммерческого CMS-продукта на стыке PHP и TypeScript: серверные шаблоны, товарные данные, REST API и интерактивный интерфейс покупки. В корзине выделены доменные типы, репозиторий API и состояние; плагин каталога разделяет контроллеры, сервисы и прикладные сценарии. Это релевантно WordPress-разработке, e-commerce, интеграциям и сопровождению существующих проектов.

## Установка и сборка

Требуются WordPress с Interactivity API, PHP 8.2+, Composer, Node.js 24 и pnpm@11.15.1.

1. Разместите репозиторий как тему `wp-content/themes/metal-theme`.
2. Установите зависимости темы и обработчика форм:

```sh
composer install
composer --working-dir=VG_Mailer install
composer --working-dir=plugins/VG_Catalog install
pnpm install
pnpm build
```

3. Скопируйте `plugins/VG_Catalog` в `wp-content/plugins/VG_Catalog`. Активируйте тему и плагин, настройте меню, страницы и товарный каталог.
4. Для каналов отправки форм создайте локальный `VG_Mailer/config.php` на основе примера и задайте свои параметры.

Ресурсы собираются в `assets/build/` и подключаются через `kucrut/vite-for-wp`. Для разработки есть `pnpm dev` и `pnpm watch`; адрес WordPress можно задать в локальном `.site-url`, например `http://localhost:8080/`.
